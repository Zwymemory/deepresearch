## 用户现在能看到什么

- **摘录**：从原回答挑选完整句子，每条可展开对应轮次，再查看完整问答和代码。
- **归纳**：按「核心知识 / 适用条件 / 练习与代码」分组，减少来源提示、格式要求等杂项。
- **去重**：合并相同或高度相近的表述，保留多轮来源；对版本、数值、否定、标识符、使用条件不同的内容采取保守处理。
- **续问**：整理后的摘录也会进入后续研究的相关上下文。原练习、用户备注和完整原回答继续保留。

这是对原回答的分类摘录，不是模型重新撰写的完整总结，也不是重新核验的知识。打开和整理笔记不会额外调用模型。每个主题最多展示 8 条，省略数量会注明；其余内容仍可从问题记录查看。
